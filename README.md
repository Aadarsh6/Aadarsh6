## Projects

**[Revive AI](https://github.com/Aadarsh6/Revenue-Recover-Razorpay-AI)** — Autonomous revenue recovery for Razorpay, built for their Buildathon. The AI only recommends; a deterministic policy engine decides, and every execution is gated by a live Razorpay re-check. A deliberate 5-webhook concurrency storm exposed a real race condition — found and fixed the root cause before shipping.

**[Terminal-Talk](https://github.com/Aadarsh6/Terminal-Talk)** *(in progress)* — A peer-to-peer encrypted chat app built from raw TCP sockets — no WebRTC, no framework hiding the network layer. Custom framing, persistent identities, encrypted history, and a real NAT-traversal experiment that failed predictably and got measured instead of hidden.

**[FocusZen](https://focuszen.aadarshm.me)** — A focus-tracking Chrome extension that's actually published on the Chrome Web Store, paired with a React dashboard for session analytics.

**[Xc Craft](https://xcraft.aadarshm.me)** — Turns an idea into a structured, ready-to-post X thread — six tone profiles, three formats, one-click publishing through the Twitter API.
