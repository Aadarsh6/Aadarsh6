## ⚡ Featured Work

### [Xc Craft](https://xcraft.aadarshm.me)
**Turns a raw idea into a structured, ready-to-post X thread.**

A custom prompt pipeline behind six tone profiles and three post formats (single / thread / long-thread), with structured JSON output, numbering validation, and fallback handling so a model hiccup never becomes the user's problem. Full OAuth + local auth on a Postgres backend, and one-click publishing straight through the Twitter API. Started on a BaaS, migrated to a custom Express backend once I needed real ownership of the stack.

Blocks distractions and tracks focus sessions, live on the Chrome Web Store for anyone to install. Paired with a React dashboard for session analytics and blocklist management — extension, backend, and web app all talking to each other as one coherent system.
